#   3.11 also works; 3.12 is chosen as the newest both stacks support.

# Resolved conflicts
#   numpy      Crucible AI pinned ==1.26.4, Crucible AI required >=2.0.
#              Resolved to 2.x: scikit-learn 1.9.0 declares numpy>=1.24.1 with no
#              upper bound, so the 1.26.4 pin was stale rather than load-bearing.
#              Arrays pickled under 1.26 still read under 2.x, so the committed
#              Crucible AI artifacts survive the move. scripts/verify_artifacts.py is
#              what proves that, and must pass before this pin is trusted.
#   pandas     Crucible AI ==2.2.3 already satisfies Crucible AI's >=2.0. 2.2.3 is the
#              release that added numpy 2 support, so it is kept exactly.
#
# Every version here is exact. A range would let a rebuild pick up a version the
# committed model artifacts were never validated against, which is precisely the
# failure this file exists to prevent.
